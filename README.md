# SIGECAD — atualizações Android

Repositório público **somente de artefatos**. O código-fonte não fica aqui.

Cada release contém:

- `SIGECAD.apk`
- `update-manifest.json` (assinado)

O SIGECAD é um aplicativo independente, não oficial, para estudantes da UFGD. No Android, o próprio app lê o manifesto, baixa o APK e pede confirmação antes de instalar.

Não envie código, keystore, chaves ou senhas para este repositório.
